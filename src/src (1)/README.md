# IF669-Jogo
Jogo em C para conclusão da cadeira IF669 (introdução à programação) no CIn-UFPE.

# Compilação e execução
Para compilar, na pasta src abra o terminal e escreva
    
    cc main.c menu/menu.c updategame/updategame.c collisions/collisions.c final/final.c -o jogo -lraylib

Para executar,

    ./jogo
